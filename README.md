## Diabetes Stage Classification

This code comprises results from 6 different classification models: LDA, QDA, KNN, Logistic Regression, Naive Bayes, and SVM

### Dataset

The dataset we used was the Diabetes Health Indicators Dataset found at [https://www.kaggle.com/datasets/mohankrishnathalla/diabetes-health-indicators-dataset](https://www.kaggle.com/datasets/mohankrishnathalla/diabetes-health-indicators-dataset)
